# 基于 Python 的智能消费行为分析与经济指标可视化平台

## 一、项目简介

本项目旨在开发一个基于 Python 的个人及家庭消费行为分析平台。

用户可以上传日常消费账单，系统对消费数据进行读取、清洗、分类、统计和分析，并通过网页和可视化图表展示消费结构、消费趋势及异常支出情况。

项目结合经济学相关指标，如恩格尔系数、平均消费倾向和边际消费倾向，帮助用户了解个人及家庭的消费情况。

系统还提供 K-Means 消费行为聚类、异常检测和 Excel 分析报告导出等功能，将原始消费账单转化为直观、易理解的分析结果。

## 二、核心功能

1. **消费账单导入与数据预处理**：支持 CSV 文件上传，检查必要字段，处理缺失值、无效日期、无效金额和重复记录。
2. **消费记录自动分类**：基于关键词规则识别餐饮、交通、购物、娱乐、住房等消费类别。
3. **消费统计与经济指标计算**：统计总收入、总支出、收支结余，并计算恩格尔系数、平均消费倾向和边际消费倾向。
4. **消费异常检测**：使用 IQR 四分位距法和 Z-score 标准分数法识别金额异常的消费记录。
5. **消费行为聚类分析**：使用 K-Means 算法，根据消费金额和消费类别对交易记录进行聚类。
6. **消费趋势分析**：统计月度消费支出，并使用移动平均法观察消费变化。
7. **数据可视化与报告生成**：通过 Streamlit、Plotly 等工具展示分析结果，并支持导出包含多个工作表的 Excel 消费分析报告。

## 四、开发环境

- 操作系统：Windows
- Python：3.13.15
- 开发工具：Visual Studio Code
- Python 虚拟环境：.venv

## 五、项目安装与运行

### 1. 下载项目并进入项目目录

在 VS Code 中打开项目文件夹。

### 2. 创建并激活虚拟环境

```bash
python -m venv .venv
```

Windows PowerShell 激活命令：

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. 安装项目依赖

```bash
pip install -r requirements.txt
```

### 4. 启动网页应用

```bash
python -m streamlit run app.py
```

启动后，在浏览器中访问：

```text
http://localhost:8501
```

### 5. 运行自动化测试

```bash
python -m pytest -v
```

## 六、测试情况

测试范围包括：

- 消费趋势分析

## 七、项目数据说明

项目中的示例账单为模拟数据，仅用于功能开发和测试，不代表真实用户的消费记录。

用户也可以上传符合系统字段要求的 CSV 账单进行分析。

## 八、项目开发目标与后续扩展

本项目以个人及家庭消费分析为核心，后续计划进一步完善以下功能：

1. 增加微信、支付宝等不同来源账单的字段识别与格式转换。

3. 接入公开 CPI 数据，分析宏观物价变化与个人消费支出的关系。
4. 完善消费趋势预测和分析报告功能。
5. 优化网页界面及用户交互体验。

通过以上功能，逐步构建一个集账单管理、消费分析、经济指标计算和可视化展示于一体的综合性消费分析平台。
