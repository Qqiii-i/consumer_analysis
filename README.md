# 基于Python的智能消费行为分析与经济指标可视化平台

## 一、项目简介

本项目是一个基于Python开发的个人消费行为分析与经济指标可视化平台，面向个人消费记录分析场景，实现从账单导入、数据清洗、消费分类到统计分析、消费预测和报告导出的完整流程。

项目采用Streamlit构建 Web交互界面，结合数据分析、机器学习和经济学指标计算方法，对个人消费数据进行多维度分析，帮助用户了解消费结构、消费习惯及变化趋势。

项目已部署至Streamlit Cloud，提供公网访问地址，无需本地配置开发环境即可体验平台功能。

- 在线体验：https://consumeranalysis-adyfksfhjwzyqtnroem9hn.streamlit.app/

## 二、核心功能

1. **数据导入与清洗**：支持CSV、Excel、JSON文件导入，支持微信支付账单专用解析；完成日期、金额转换及数据质量检查。
2. **自动消费分类**：结合关键词规则与TF-IDF+朴素贝叶斯算法进行消费分类，支持手动修改分类结果。
3. **经济学分析指标**：计算收入、支出、结余、储蓄率、恩格尔系数、平均消费倾向（APC）和边际消费倾向（MPC）。
4. **CPI与个人消费分析**：结合CPI数据分析名义消费与实际消费水平及其变化趋势。
5. **消费统计与趋势分析**：展示消费金额、分类占比、消费频率、日周月年趋势及移动平均等统计结果。
6. **消费预测**：根据最近三个月的消费数据，使用移动平均基线方法预测下个月的消费金额。
7. **异常消费检测**：使用IQR和Z-score两种统计方法识别金额异常的消费记录。
8. **消费行为聚类**：使用K-Means算法，根据消费金额和消费类别对交易记录进行聚类，分析不同消费群体特征。
9. **分析报告导出**：支持导出包含消费统计、经济指标及分析结果的 Excel 和 PDF 报告。

## 五、项目安装与运行

### 1. 下载项目并进入项目目录

```bash
git clone https://github.com/Qqiii-i/consumer_analysis.git
cd consumer_analysis
```

### 2. 创建并激活虚拟环境

Windows PowerShell激活命令：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. 安装项目依赖

```bash
python -m pip install -r requirements.txt
```

### 4. 启动网页应用

```bash
python -m streamlit run app.py
```

启动后，在浏览器中访问：

```text
http://localhost:8501
```

项目采用多页面导航结构，用户可以从首页进入各个功能模块，按照数据导入、消费分类、数据分析和报告导出的流程使用平台。

此外，项目已部署至Streamlit Cloud，可通过公网网址直接访问。

## 七、项目数据说明

项目支持用户导入个人消费账单，普通账单支持CSV、Excel和JSON格式，微信支付账单支持专用Excel解析。

统一数据格式主要包含以下字段：
| 字段 | 说明 |
|---|---|
| transaction_id | 交易编号 |
| transaction_date | 交易日期 |
| description | 交易描述 |
| amount | 交易金额 |
| transaction_type | 交易类型 |
| category | 消费类别 |
| payment_method | 支付方式 |

此外，项目使用本地 CPI 数据文件进行经济指标分析，相关数据包含月份及 CPI 指数信息。

项目提供账单模板，方便用户按照统一格式导入数据。对于真实消费账单，建议在上传和展示前对交易编号及私人消费描述等敏感信息进行脱敏处理。

## 八、项目开发目标与后续扩展

### 1 项目开发目标

- 综合运用Python编程、数据处理、机器学习和数据可视化等知识，开发具有实际应用价值的数据分析平台。
- 实现个人消费账单的自动化处理与分类，降低人工整理成本。
- 结合经济学指标分析个人消费结构和消费行为。
- 通过数据可视化和报告导出，提高消费数据的可读性和实用性。

- 数据导入扩展：增加支付宝账单、银行卡账单等更多数据来源的兼容能力。
- 分类模型优化：扩充消费关键词库，优化分类模型，提高小样本条件下的分类效果。
- 预测功能优化：引入更多时间序列预测方法，对不同预测模型的效果进行比较。
- 分析功能完善：增加更丰富的消费行为分析指标和个性化消费建议。
- 系统功能完善：优化页面布局、提高代码复用性，并完善系统集成测试与异常处理机制。
